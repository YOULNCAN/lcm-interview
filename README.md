# 李能 · 乐创盟技术部面试网站

12屏交互演示，适合线上面试共享屏幕。以已确认PPT与面试文案为内容依据，建议陈述约4分钟，由讲述者手动切屏。

## 使用

直接用 Edge 或 Chrome 打开网站目录中的 `index.html`（本地成品位于 `dist/`，在线仓库位于根目录）。网页字体、脚本与样式均在本地，无需安装依赖；作品链接需要联网。

- 方向键、空格、PageUp / PageDown：切屏；Home / End：首尾。
- F：全屏；O：页面总览；Esc：关闭总览或图片。
- 图片点击可放大；查看器内方向键切换同屏图片，“查看原尺寸”可查看图片细节。
- 右上角闪电按钮切换动效，并在浏览器允许时保存偏好；尊重系统减少动态效果设置。
- 手机可在当前屏内上下浏览，底部按钮切换页面。
- 作品在新标签页打开；扣子作品入口已标注需登录。

## 源码与部署

`index.html`、`styles.css`、`full.css`、`app.js` 与 `assets/` 构成完整静态网站源码，无第三方运行时依赖。图片保持原始文件内容。本地成品集中在 `dist/`；发布仓库将这些文件直接放在根目录，选择默认分支根目录作为 GitHub Pages 发布来源。

设计参考 Vercel、Apple、Linear 及 reveal.js 官方页面的视觉与演示交互思路，代码独立编写，未复制其品牌素材或源代码。网站截图为李能已有项目的真实截图；梵高主题网页中的画作原作属于梵高。证书为课程与平台学习记录，短剧为分镜展示阶段。

不公开面试追问准备文档。原PPT、Word和三屏样机保留在原目录。
